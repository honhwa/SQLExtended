# 2026-11-04

## 修复 VsSDK.targets 导入失败（IDE 报 "was not imported ... due to the file not existing"）

- 现象：SQLExtended.csproj 第 366 行 Import 报错，错误路径为 `G:\nuget\packagesmicrosoft.vssdk.buildtools\...`。
- 根因：用户级 `%APPDATA%\NuGet\NuGet.Config` 的 `globalPackagesFolder` 写成 `G:\nuget\packages`（无尾部分隔符），
  NuGet 原样写进 `obj\*.nuget.g.props` 的 `$(NuGetPackageRoot)`；手写的
  `$(NuGetPackageRoot)microsoft.vssdk.buildtools\...` 直接拼接导致 `packages` 与包名粘连。NuGet 自己生成的
  import 都写成 `$(NuGetPackageRoot)\microsoft...`，所以只有这一行出问题。
- 修复：改为 `<Import Project="$(PkgMicrosoft_VSSDK_BuildTools)\tools\vssdk\Microsoft.VsSDK.targets" />`，
  并给 PackageReference 加 `GeneratePathProperty="true"` 保证该属性被生成；顺带消除了硬编码版本号。
- 注意：本机沙箱禁止执行 MSBuild/dotnet build，只做了 XML 合法性 + 目标文件存在性静态校验，需在 VS 内重新加载项目验证。
