DataByte for SSMS 2026.10.19.1637

New
- Go to Column in the results grid. With many columns returned, press Ctrl+Alt+K (or right-click the grid and choose Go to Column…) and type part of a column name: the list narrows as you type, best match first. Exact names come first, then names that start with what you typed, then a word inside the name (`qty` finds Ongoing_Qty and OngoingQty), then anywhere in the name, then initials (`oqd` finds OngoingQtyDate). Each column shows its data type and its position on screen, so two columns with the same name from a join can be told apart. Up and Down move through the list while you keep typing; Enter takes the grid to that column in the row you were on, scrolls it into view and puts the focus back in the grid. With more than one result set, the grid you were in is listed first and the others are labelled Result 2, Result 3 and so on.
- IntelliSense: synonyms. A synonym is now offered where the object it points at would be: synonyms for tables and views after FROM and JOIN (with an alias, like a table), synonyms for procedures after EXEC, and synonyms for functions after `dbo.`. The list shows what each one points at, and there is a Synonyms filter button. Columns come through the synonym too: `FROM dbo.MySynonym s WHERE s.` lists the columns of the table behind it, and EXEC parameter expansion works for a procedure synonym. A synonym whose target cannot be read (on a linked server, or in a database you have no access to) is offered after both FROM and EXEC.
- IntelliSense: linked servers. Linked server names are offered after FROM, JOIN and EXEC, inside `OPENQUERY(` and after `EXEC (…) AT`. Settings → IntelliSense → Linked servers chooses how far it goes: Off, Names (the default), Names and databases, or Names, databases, tables and columns. The two higher levels read from the linked server itself, so they wait on that server: `LinkedServer.` lists its databases, `LinkedServer.Sales.` its schemas, `LinkedServer.Sales.dbo.` its tables and views, and an alias on a four-part name lists that table's columns. The first time each of these is asked for, the list comes back empty while it is read; the next time it is there. Procedures on a linked server are not listed. A synonym that points at a linked server gets its columns the same way.
- Schema Cache window: a Linked servers branch under each server. It shows each linked server's product and data source, how many databases have been read, and for each database the number of tables, views and synonyms and how many tables have had their columns read. Anything that could not be read shows as failed, with the reason in a tooltip. Right-click to read the list again, or to load or refresh a linked server's databases or a database's tables.

Changed
- The schema cache now records what each synonym points at. Synonyms already in the cache show as "target unknown" until that database is next fully refreshed.

Fixed
- IntelliSense now works while you are part way through a bracketed name that contains a space or a backslash, such as `FROM [My Ta` or `OPENQUERY([SERVER\INST`.
