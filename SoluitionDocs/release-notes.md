DataByte for SSMS 2026.9.23.1425

Changed
- The SQLExtended menu is reorganised into groups that read from the query editor outwards: editor actions (View Schema, Format SQL, Parse Statistics), tool windows (SQL Search, SQL History, Script Library, Validate Schema References), results grid (Find in Results, Grid Aggregates, Script Results as INSERT), monitoring (Performance Monitor, Agent Jobs, Always On Monitor, Replication Monitor), schema cache, servers (Environment Tabs, Regroup Servers Now), and settings (Settings, Formatter, Snippets, Check for Updates). Previously the results-grid commands and Parse Statistics sat among the tool windows, Regroup Servers Now sat in the cache group, and Formatter and Snippets — both settings dialogs — sat beside Format SQL.
- Settings: the pages are now a list down the left side of the dialog instead of fifteen tabs across the top. The tabs wrapped into two or three rows that WPF reshuffled on every click, so the page you had just picked jumped to a different row. The list uses brighter text, and the current page is marked with the selection colour, an accent bar and bold text — before, the selected tab was darker than the unselected ones in the dark theme, and hovering over it hid the selection altogether. Section headings and the help text under each option are also easier to read in dark mode, and the dialog opens wider to make room for the list.
- The extension's own windows and dialogs now follow the SSMS colour theme — Dark, Light, Blue or a custom theme — instead of always drawing in dark, and switch with it when you change theme under Tools > Theme.

Fixed
- Refresh All Databases and Clear Schema Cache were missing from the SQLExtended menu. Both commands existed and worked, but the menu SSMS 22 actually shows never listed them. They are now in the schema cache group.
